## Reconciled findings and limits

- Routing: page 19 agrees with application snapshot
  `986ae759c1c76fe23967a8e61489d986b2bb9a51`, `src/lib/swap/fontes.ts`.
  Detailed projections already separated CoW limit orders from quote sources.
  Two generic paragraphs in `knowledge/z-swap.md` still implied comparing
  multiple sources per operation; now they describe the selected source and
  returned route. Classification and agent access are unchanged.
- Fees and Founder Pass: existing curated qualifiers preserve conditional fees,
  separate third-party costs, the shared 36-month clock and unopened sale.
  This is agreement between dated sources, not certification of today's fees.
- Interfaces: this paper does not supply an approved third-party API contract.
  Keep the existing public-interface NOT_PUBLISHED behavior and never substitute
  internal routes or infrastructure addresses. Absence here is not proof that
  no later official API can exist.
- CEX: keep the ten-venue enumeration separate from execution certification,
  permissions and disabled automation. A registry entry is not live acceptance.
- Portfolio conflict resolved against application snapshot `986ae759c1c76fe23967a8e61489d986b2bb9a51`:
  `src/lib/portfolio/avaliacao.ts` distinguishes missing prices from zero and
  marks partial totals; `src/components/portfolio/PortfolioView.tsx` counts
  unavailable balances, presents partial/unavailable labels and excludes partial
  totals from history recording. The existing projection's statement that failures
  remain indistinguishable from an empty balance was stale. It now explains the
  partial total and unavailable information without exposing implementation.
- Source completion: **83/83 visually classified**. Broader source-to-runtime
  certification is not established by this ledger.
- Runtime/model acceptance remains separate: this review neither fixes the
  recorded live generation failure nor validates a new model/provider.
